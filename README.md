# DogCareAI

평소 대비 생활 변화, 유사 사례, 수의학 문헌과의 증상 비교를 확인하는 Streamlit 웹앱입니다.

- 공개 앱: https://gwinweskgtxcbsz5nczny5.streamlit.app/
- GitHub: https://github.com/blue13244/DogCareAI

생활 패턴 모델은 사용자 제공 **교육용 합성 데이터 100건**으로 학습했습니다. 증상 비교는 별도의 문헌 대조 기능입니다. 참고용이며 수의사의 진단을 대신하지 않습니다.

## 기능

| 메뉴·결과 | 제공 내용 |
|---|---|
| 강아지 상태 설문 | 크기, 나이, 체중, 복용 여부, 평소 대비 5개 변화, 구토·설사·기침·보행 이상 |
| 생활 변화 패턴 | Random Forest 학습 라벨 분류, K-Means 군집과 군집 평균 |
| 유사 사례 비교 | 전처리 공간에서 가까운 서로 다른 개체 5건과 모델 거리 |
| 관련 증상 비교 | 12개 문헌 항목별 일치 수, 비교 가능한 수, 미확인 수, 응답별 대조와 출처 |
| 체중·나이·크기 | 같은 크기의 학습 자료 평균 체중, 나이·크기별 관리 참고정보 |
| CSV 일괄 분석 | 생활 패턴, 증상 비교 요약 및 12개 항목별 개수 열, 행별 상세 보기 |
| 증상 비교 자료 | 비교에 사용하는 문헌 징후 목록과 원문 링크 |
| 모델·데이터 | 그룹 교차검증 결과, 혼동행렬, 사용 변수 및 데이터 표시 |

긴급 징후는 증상 일치 수와 관계없이 즉시 진료를 우선 안내합니다. 입력 기록은 서버 파일이나 데이터베이스에 자동 저장하지 않습니다. 필요한 결과 CSV는 직접 내려받을 수 있습니다. 공개 저장소의 원본 CSV에는 사용자가 제공한 합성 기록만 들어 있습니다.

## 증상 비교 결과 읽기

음수량 4, 배뇨량 4, 식사량 3이면 당뇨병 관련 문헌 항목은 **3개 비교 중 2개 일치, 미확인 1개**로 표시됩니다. 문헌에서 선택한 음수·배뇨·식사 증가와 시간에 따른 체중 감소 중 앞의 세 항목을 비교하고, 단일 체중으로 알 수 없는 체중 감소는 미확인으로 남깁니다.

1·2는 감소, 3은 평소와 같음, 4·5는 증가입니다. 이진 증상은 0·1로 대조합니다. 관찰하지 않은 값을 평소와 같음이나 증상 없음으로 대신 입력하지 마세요. CSV에 없는 긴급 징후는 미확인입니다. 수면시간·나이·크기·체중·약물복용은 증상 일치 수에 더하지 않습니다.

각 문헌에서 선택한 징후 수가 다릅니다. 일치 수를 백분율·질환 순위·중증도·진료 우선순위로 바꾸지 않습니다. 여러 질환에 같은 징후가 겹치며, 일치하지 않아도 질환을 배제할 수 없습니다. 자세한 항목과 한계는 [SYMPTOM_COMPARISON.md](SYMPTOM_COMPARISON.md)를 참고하세요.

## 로컬 실행

Python 3.12에서 프로젝트 폴더를 열고 실행합니다.

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python train.py
python -m streamlit run app.py
```

저장 모델은 저장소의 신뢰하는 파일만 불러옵니다. 외부 joblib 파일 업로드는 지원하지 않습니다. CSV 해시·스키마·scikit-learn 버전이 다르면 현재 환경에서 CSV로 메모리 재학습합니다. 문헌 비교 항목 수정에는 모델 재학습이 필요하지 않습니다.

## CSV 형식

분석에는 아래 13개 열이 필요합니다. UTF-8(BOM 포함 가능) 또는 CP949를 지원합니다.

| 열 | 값 |
|---|---|
| 나이_세 | 0~35 |
| 체중_kg | 0 초과~150 |
| 식사량, 음수량, 배뇨량, 활동량, 수면시간 | 정수 1~5 |
| 증상_구토, 증상_설사, 증상_기침, 증상_보행이상 | 0 또는 1 |
| 크기 | 소형견·중형견·대형견 |
| 약물복용 | 영문 O 또는 X |

이름·ID·라벨 없이도 분석합니다. 입력 누락·범위 오류·중복 열은 오류로 알려 줍니다. 일괄 결과의 `C01_일치수`, `C01_비교수`, `C01_미확인수` 등은 문헌 항목별 개수입니다. ID별 의미는 비교 문서에 있습니다. CSV에는 긴급 징후·지속 시간 정보가 없어 개별 진료 안내는 설문에서 확인하세요.

## 모델 평가와 검사

5개 그룹 교차검증 정확도 91.0%, macro F1 0.904, 최빈 라벨 기준선 38.0%입니다. 동일 ID 또는 동일 입력은 같은 그룹으로 묶었습니다. **합성 라벨 재현 성능**이며 임상 성능이 아닙니다. 전체 학습·한계는 [MODEL_CARD.md](MODEL_CARD.md), 실행 결과는 [VALIDATION.md](VALIDATION.md)에 있습니다.

```bash
python -m unittest discover -s tests -v
# 모델 패키지 없이 문헌 비교만 검사
python -m unittest discover -s tests -p test_symptom_compare.py -v
```

문헌에서 선택한 항목·고정 순서·미확인 처리·긴급 안내 보존을 검사합니다. 질환별 민감도·특이도나 임상 유효성은 검증하지 않았습니다.
